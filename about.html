About InterSurv

Intelligent Survey Control Point Navigation

InterSurv is a mobile and web-based control point navigation system designed to help users locate and manage survey control points within Politeknik Merlimau Melaka.

Key Features

📍 Control Point Location

Locate survey control points directly on the map.

📊 Survey Information

View coordinates, elevation, bearing and distance information.

🗺️ Map & Traverse

Visualise selected control points and their traverse connections.

📷 Control Point Photos

View photographs associated with individual control points.

How to Use InterSurv

1

Press START to open the Poly Map and begin searching for control points.

2

Search for the required control point using the search bar.

3

Select the control point to view its location and detailed survey information.

4

Use NAVIGATE to view the direction and information required to reach the selected station.

5

Use ADD CONTROL POINT to select additional points and view the traverse, bearing and distance information.
